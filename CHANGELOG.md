# Changelog

## 1.0.0 - 2026-11-20

- Primera versión: la ventana **Window → Analysis → Tilt Simulator** y la API `TiltSimulator`. Sensores virtuales del
  Input System (`AttitudeSensor`, `GravitySensor`, `Gyroscope`, `Accelerometer`), tres formas de sostener el teléfono,
  sensores a elección, valores en los ejes del dispositivo según la orientación de la pantalla y respuesta a la
  frecuencia de muestreo. Incluye el ejemplo **Tilt Demo**.
